# Disclaimer

This repository documents security research on a device the author owns.

**Do not use this on a vehicle you do not own or have written permission to test.**
Unauthorised access to a computer system is a crime in most countries.

The scripts here can start apps, read files, take screenshots, and change the
head unit's runtime state. Some documented RPC methods can reflash ECUs, change
the VIN, wipe Wi-Fi credentials, or disable the unit. Those methods are listed
only so you know what to avoid. Do not call them.

Nothing in this repository:

- contains a private key, certificate, password, token, or API credential;
- lets you impersonate a vehicle to Ola's backend;
- is intended to bypass a paid feature, a warranty, or a safety limit;
- has been tested against a moving vehicle.

The authors accept no liability for damage, injury, legal action, or loss of
warranty resulting from use of this material.

If you find a new vulnerability, report it to the vendor first. Give them time to
fix it before you publish.
